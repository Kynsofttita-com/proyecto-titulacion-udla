================================================================================
CÓMO TESTEAR TUS ENDPOINTS (Sprint 12)
================================================================================

Opción 1: curl (línea de comandos)

  # Login primero (tomar token)
  curl -X POST http://localhost:8080/auth/login \
    -H "Content-Type: application/json" \
    -d '{"email":"admin@escuela.local","password":"Admin123!"}'

  # Resultado: {"accessToken":"eyJhbG..."}

  # Luego usar el token en endpoints autenticados:
  curl -X GET http://localhost:8080/notificaciones \
    -H "Authorization: Bearer eyJhbG..."

Opción 2: Postman (GUI)

  1. Descargar Postman: https://www.postman.com/downloads/
  2. Crear una nueva Request:
     - Method: POST
     - URL: http://localhost:8080/auth/login
     - Body (JSON):
       {
         "email": "admin@escuela.local",
         "password": "Admin123!"
       }
     - Send
  3. Copiar el "accessToken" del resultado
  4. Nueva Request para tu endpoint:
     - Method: GET
     - URL: http://localhost:8080/notificaciones
     - Headers: Add "Authorization: Bearer <tu-token>"
     - Send

Opción 3: Swagger UI (en el navegador)

  1. Ir a http://localhost:8088/swagger-ui.html (MS-Notificaciones)
  2. Click en un endpoint
  3. Click "Try it out"
  4. Llenar parámetros
  5. Click "Execute"
  6. Ver respuesta

================================================================================
DEBUGGING — Cómo investigar si algo falla
================================================================================

Mi endpoint retorna 404 (Not Found)
  1. Ver si el MS está registered en Eureka:
     http://localhost:8761 → buscar tu MS en la lista
  2. Ver si Gateway tiene la ruta correcta:
     http://localhost:8080/actuator/gateway/routes → buscar tu ruta
  3. Ver logs del MS:
     docker logs -f ms-notificaciones

Mi endpoint retorna 500 (Error)
  1. Ver logs:
     docker logs -f ms-notificaciones
  2. Buscar "Exception" o "ERROR" en los logs
  3. Ir a la línea indicada en el código y revisar lógica

Mi endpoint retorna 403 (Forbidden / Unauthorized)
  1. Verificar que pasaste el token en header:
     Authorization: Bearer <tu-token>
  2. Verificar que el token no expiró (24 horas de duración)
  3. Verificar que tu usuario tiene el rol necesario:
     - admin@escuela.local tiene rol ADMIN (todos los permisos)

Mi email no se envía
  1. Ver si hay error en logs de MS-Notificaciones:
     docker logs -f ms-notificaciones
  2. Ver si el evento llegó a RabbitMQ:
     http://localhost:15672 → Queues → buscar cola de notificaciones
  3. Ver si Mailtrap recibió el email:
     Ir a https://mailtrap.io → Inbox dev

Mi reporte no genera datos
  1. Verificar que existen registros en la BD:
     http://localhost:8888 → ejecutar query SQL
  2. Revisar lógica del reporte en el Service
  3. Ver logs de MS-Reportes:
     docker logs -f ms-reportes
