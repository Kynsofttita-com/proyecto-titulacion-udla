## 🔧 SI SIGUE SIN FUNCIONAR

### Opción 1: Actualizar campos
1. Presiona **Ctrl+A** (seleccionar todo)
2. Presiona **F9** (actualizar campos)
3. Intenta de nuevo: REFERENCIAS → Insertar índice

### Opción 2: Verificar etiqueta
1. Haz clic en un caption cualquiera
2. Verifica que en REFERENCIAS → Insertar Título aparezca "Figura"
3. Si dice "Tabla", hay un error
4. Intenta generar el índice nuevamente

### Opción 3: Limpiar y reconstruir
1. Ve a REFERENCIAS → Insertar Título
2. Etiqueta: "Figura"
3. Posición: Bajo la selección
4. ✅ Haz clic en CREAR ETIQUETA
5. Luego intenta generar el índice

## 📝 ESTRUCTURA DEL CAPTION

Cada figura tiene esta estructura (reconocible por Word):

```
Figura [NÚMERO AUTOMÁTICO]
Título de la figura. Nota. Descripción profesional.
```

**Ejemplo**:
```
Figura 1
Diagrama Ishikawa de causas de ineficiencia en el control 
administrativo de escuelas de conducción. Nota. Muestra el 
análisis de causa-efecto identificando factores críticos en 
la gestión operativa.
```

3. Presiona F9 para actualizar
