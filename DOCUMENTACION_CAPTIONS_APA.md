## 🎨 FORMATO VISUAL

### Encabezado de Caption
```
Figura N
```
**Propiedades**:
- Tamaño: 10 pt
- Color: Negro
- Estilo: Normal

### Título
```
Título descriptivo en itálica
```
**Propiedades**:
- Tamaño: 10 pt
- Color: Negro
- Estilo: **Itálica**
- Punto final: Sí

### Nota Explicativa
```
Nota. Descripción profesional adicional.
```
**Propiedades**:
- Tamaño: 10 pt
- Color: Negro
- "Nota." en negrita
- Descripción en normal

| Elemento | Requerimiento APA | Status |

| Numeración | Figura 1, Figura 2, etc. | ✅ |

| Formato Nota | "Nota." en negrita | ✅ |

| Color | Preferiblemente negro | ✅ |
