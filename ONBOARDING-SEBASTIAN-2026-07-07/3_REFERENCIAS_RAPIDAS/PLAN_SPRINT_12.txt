TAREA 2: MS-REPORTES
================================================================================

Objetivo: Reportes operacionales + financieros con export PDF/Excel

Subtareas:
  ✓ 2.1 - Reportes Operacionales
    - Controller GET /reportes/estudiantes?fechaInicio&fechaFin
      Retorna: total estudiantes, nuevos, activos, inactivos, progreso
    - Controller GET /reportes/instructores?fechaInicio&fechaFin
      Retorna: instructores activos, horas impartidas, disponibilidad
    - Controller GET /reportes/vehiculos?fechaInicio&fechaFin
      Retorna: vehículos activos, km recorridos, mantenimiento pendiente

  ✓ 2.2 - Reportes Financieros
    - Controller GET /reportes/financiero?fechaInicio&fechaFin
      Retorna: ingresos totales, por categoría, facturas pendientes, deuda
    - Análisis de cobranza (pagados, vencidos, en cobranza)
    - Reconciliación factura_cuotas

  ✓ 2.3 - Export PDF/Excel
    - Dependencia: Apache POI (Excel), iText (PDF)
    - Controller POST /reportes/exportar
      Body: { tipo: "operacional|financiero", formato: "pdf|excel" }
      Response: descarga archivo
    - Tests con archivo generado

  ✓ 2.4 - Dashboard KPIs (preparación backend)
    - Controller GET /reportes/kpis
      Retorna: estudiantes_activos, ingresos_mes, deuda_total, instructores_activos
    - Cache Caffeine (caducidad: 1 hora)

Criteria de aceptación:
  ✓ Todos los reportes generan datos correctos
  ✓ Excel y PDF se descargan sin errores
  ✓ Cobertura ≥ 75%
  ✓ KPIs están cacheados
  ✓ Documentación en código

Estimación: 6-7 días
