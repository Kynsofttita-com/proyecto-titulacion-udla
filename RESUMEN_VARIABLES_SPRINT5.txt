🚀 CÓMO USAR EN POSTMAN
═══════════════════════════════════════════════════════════════════════════════════

PASO 1: IMPORTAR COLECCIÓN
─────────────────────────────
1. Abre Postman
2. File → Import
3. Selecciona: POSTMAN_Sprint5_Collection_v2.json
4. Click "Import"

PASO 2: CAMBIAR VARIABLES (Haz esto ANTES de empezar)
────────────────────────────────────────────────────
1. En Postman, haz click en el nombre de la colección (arriba a la izquierda)
2. Pestaña "Variables"
3. Localiza y MODIFICA:

   cedula                  → 1234567891         (cambia el 0 final)
   email                   → estudiante1@...    (personaliza)
   cedulaInstructor        → 9876543211         (cambia el 0 final)
   emailInstructor         → instructor1@...    (personaliza)
   licencia                → 1A123457           (cambia el 6 final)
   nombreCompleto          → Tu nombre          (personaliza)
   nombreInstructor        → Otro nombre        (personaliza)

4. Click "Save"

PASO 3: EJECUTAR ENDPOINTS
──────────────────────────
1. Colección → 1 AUTENTICACIÓN → Login
   ✅ Ejecuta → obtiene token automáticamente

2. Colección → 2 MS-ESTUDIANTES CRUD
   ✅ POST /estudiantes → crea
   ✅ GET /estudiantes → lista todos
   ✅ GET /estudiantes/{id} → detalle (usa {{estudianteId}})
   ✅ PUT /estudiantes/{id} → actualiza
   ✅ DELETE /estudiantes/{id} → elimina

3. Colección → 3 MS-INSTRUCTORES CRUD
   ✅ Igual que estudiantes pero con instructor

4. Colección → 4 ERROR HANDLING
   ✅ Prueba errores: duplicados, sin auth, no encontrado

⚠️  PROBLEMAS Y SOLUCIONES
═══════════════════════════════════════════════════════════════════════════════════

PROBLEMA: "409 Conflict - Cédula duplicada"
CAUSA:    Ya existe un estudiante/instructor con esa cédula
SOLUCIÓN: Cambiar cedula/cedulaInstructor a número diferente
          Ej: 1234567891 → 1234567892

PROBLEMA: "409 Conflict - Email duplicado"
CAUSA:    Ya existe un estudiante/instructor con ese email
SOLUCIÓN: Cambiar email/emailInstructor a email diferente
          Ej: estudiante@... → estudiante1@escuela.local

PROBLEMA: "409 Conflict - Licencia duplicada"
CAUSA:    Ya existe un instructor con esa licencia
SOLUCIÓN: Cambiar licencia a número diferente
          Ej: 1A123456 → 1A123457

PROBLEMA: "401 Unauthorized"
CAUSA:    JWT token expiró o no existe
SOLUCIÓN: Ejecutar endpoint "Login" nuevamente para obtener token fresco

PROBLEMA: "404 Not Found"
CAUSA:    El estudiante/instructor no existe (ID incorrecto)
SOLUCIÓN: Crear primero (POST) o usar ID válido existente

PROBLEMA: "Cannot read variable..."
CAUSA:    Postman no ve las variables
SOLUCIÓN:
  1. Verifica que la colección está importada
  2. Verifica que seleccionaste el Environment correcto
  3. Recarga la página de Postman (F5)
