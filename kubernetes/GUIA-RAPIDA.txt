🎯 LO MÁS IMPORTANTE A ENTENDER
================================================================================

Git es la FUENTE DE VERDAD:

  [Tu código en GitHub]
           ↓
    [Argo CD lo monitorea]
           ↓
    [Detecta cambios automáticamente]
           ↓
    [Actualiza Kubernetes sin comandos manuales]
           ↓
    [Sistema siempre coincide con el código]


¿QUÉ SIGNIFICA ESTO?
  - Cambios en Git → automáticamente en Kubernetes
  - Si alguien modifica Kubernetes manualmente → Argo CD lo revierte
  - Sin "kubectl apply" manuales, todo es declarativo
  - Auditoría completa: git log = historial de cambios

🔄 FLUJO TÍPICO - GitOps en acción (5 minutos)
================================================================================

PASO 1: Cambiar algo en Git
  → Edita: kubernetes/argocd/apps/01-api-gateway.yaml
  → Cambio: replicas: 1 → replicas: 3
  → Commit: git add . && git commit -m "Sprint 12 (..."
  → Push: git push origin main

PASO 2: Argo CD lo detecta (10-30 segundos)
  → Entra a UI: https://localhost:8443
  → Ve: Estado "OutOfSync" ⚠️
  → Espera o clickea "Sync"

PASO 3: Argo CD aplica cambios (automático)
  → kubectl apply -f manifiestos nuevos
  → Kubernetes crea 2 pods más de api-gateway

PASO 4: Verificar sincronización
  → UI muestra: "Synced" ✅
  → Terminal: kubectl get pods -n escuela-conduccion | grep api-gateway
  → Resultado: 3 pods corriendo (antes había 1)

🚀 COMANDOS ÚTILES (Copy-paste)
================================================================================

# EMPEZAR
minikube start --cpus=4 --memory=8192
kubectl create namespace argocd
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml

# ACCEDER
kubectl port-forward svc/argocd-server -n argocd 8443:443        # Argo CD UI
kubectl port-forward svc/frontend -n escuela-conduccion 3000:80   # Frontend
kubectl port-forward svc/api-gateway -n escuela-conduccion 8080:8080  # Gateway

# VERIFICAR
kubectl get pods -n argocd                                        # Argo CD pods
kubectl get pods -n escuela-conduccion                            # App pods
kubectl get svc -n escuela-conduccion                             # Services
kubectl logs <pod-name> -n escuela-conduccion -f                  # Logs

# GIT (GitOps demo)
git add kubernetes/
git commit -m "Sprint 12 (Cambio de replicas)"
git push origin main

# VER ESTADO ARGO CD
kubectl get application -n argocd
kubectl describe application escuela-conduccion -n argocd

# BORRAR TODO (reset)
kubectl delete namespace escuela-conduccion
kubectl delete namespace argocd
minikube delete

⚠️  PROBLEMAS COMUNES Y SOLUCIONES
================================================================================

PROBLEMA: "ImagePullBackOff" en pods
SOLUCIÓN:
  eval $(minikube docker-env)              # Configurar Docker
  docker build -t api-gateway:latest ./backend/api-gateway
  docker build -t ms-auth:latest ./backend/ms-auth
  docker build -t ms-estudiantes:latest ./backend/ms-estudiantes
  docker build -t frontend:latest ./frontend
  docker pull springcloud/eureka:latest && docker tag ... eureka-server:latest

PROBLEMA: No puedo entrar a Argo CD UI
SOLUCIÓN:
  kubectl port-forward svc/argocd-server -n argocd 8443:443
  Abrir en navegador: https://localhost:8443

PROBLEMA: Application está OutOfSync y no sincroniza
SOLUCIÓN:
  1. Editar kubernetes/argocd/argo-app.yaml
  2. Reemplazar URL de repositorio con la tuya
  3. kubectl apply -f kubernetes/argocd/argo-app.yaml
  4. Clickear "Sync" en UI

PROBLEMA: PostgreSQL falla
SOLUCIÓN:
  kubectl logs postgres-... -n escuela-conduccion -f
  Ver qué dice el error

PROBLEMA: Minikube se queda sin memoria
SOLUCIÓN:
  minikube stop
  minikube start --memory=12288  # Aumentar memoria

Ver más en: SETUP-ARGOCD.md → Troubleshooting
